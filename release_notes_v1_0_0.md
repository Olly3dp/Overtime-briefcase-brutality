# 🚀 Release Notes - v1.0.0 (Initial Public Release)

**OVERTIME: Briefcase Brutality** — *Official Arcade Launch*

We are thrilled to announce the official v1.0.0 release of **OVERTIME: Briefcase Brutality**, a retro-styled 2D action arcade game built from scratch using pure HTML5 Canvas, JavaScript, and Web Audio API!

---

## 🔥 Key Features & Highlights

### 🕹️ 1. Core Mechanics & Arcade Combat
* **Boomerang Briefcase System:** Weaponize heavy executive steel briefcases. Throw up to 3 briefcases that automatically return to Kai upon reaching maximum flight range.
* **Responsive Platforming:** High-precision physics for moving, double-jumping, running, and dodging.
* **Dynamic Reload & Ammo Management:** Automatic cooldown timer once all 3 briefcase charges are depleted.

### 🏙️ 2. 20 Progressive Stages & Boss Battles
* **20 Unique Level Configurations:** Scaling difficulty curve across 20 distinct stages featuring distinct atmospheric lighting and enemy spawns.
* **20 Custom Stage Bosses:** Defeat iconic boss encounters (*Azazel, Belial, Malphas, Mammon, Abaddon, Baal*) with dynamic health bars and custom hitboxes.
* **Stage Exit Portals:** Defeating stage bosses activates an exit portal to advance smoothly to the next level upon interaction or touch.

### 🎨 3. HD 2D Pixel Art & Visual Effects
* **Custom Character Sprites:** Arcade-style humanoid animations for Kai (featuring headband, vest, visor, and briefcase swing frames) inspired by *Total Carnage* and classic 2D fighters (*KOF*).
* **Title Screen Artwork:** Arcade menu graphics depicting Kai fleeing from a horde of cybernetic mutant demons.
* **Parallax City Backgrounds:** Multi-layered post-apocalyptic cityscape backdrop with dynamic scroll tracking.

### 🔊 4. Web Audio Synthesizer Engine
* **Zero External Dependencies:** Built-in real-time oscillator audio synthesis using the HTML5 Web Audio API.
* Dynamic sound FX triggers for briefcase swings, hits, item pickups, and level clear events.

---

## 🛠️ Technical Stack
* **Language:** JavaScript (ES6+)
* **Rendering:** HTML5 2D Canvas API (60 FPS Game Loop via `requestAnimationFrame`)
* **Audio:** Web Audio API (`AudioContext`)
* **Distribution:** Zero-build single file deployment compatible with GitHub Pages.

---

## 🎮 How to Play
1. **Move:** `Arrow Keys` or `A` / `D`
2. **Jump:** `Spacebar` or `W` / `Up Arrow`
3. **Attack (Throw Briefcase):** `Z` or `J`
4. **Advance Stage / Confirm:** `ENTER`
