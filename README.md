# Overtime-briefcase-brutality
OVERTIME: Briefcase Brutality is a fast-paced 2D retro action arcade game powered by HTML5 Canvas &amp; Web Audio API. Take control of Kai, weaponize heavy steel briefcases as boomerangs, and slice through hordes of demonic mutants and 20 unique stage bosses to survive the shift! Playable directly in the browser with full stage progression.
